Введение

NexTT — это программа для автоматического подбора аналогов радиаторов LaggarTT из спецификаций конкурентов. Она поддерживает форматы Excel, PDF и Word, автоматически распознаёт названия радиаторов и помогает сформировать итоговую спецификацию.

💡 Ключевая особенность: Программа обучается на ваших ручных подборах. Достаточно один раз указать аналог для нераспознанного радиатора — и в следующий раз все похожие названия будут подобраны автоматически.

Первый запуск

  1. Убедитесь, что в папке с программой присутствует файл Мономатрица.xlsx (база радиаторов LaggarTT)
  2. Запустите файл NexTT.exe
  3. Дождитесь загрузки данных (в статусной строке появится сообщение о готовности)
  4. Нажмите «Загрузить данные» и выберите спецификацию для обработки

Загрузка файлов

Программа поддерживает следующие форматы:

  • Excel — .xlsx, .xls, .xlsm
  • CSV/TSV — .csv, .tsv, .txt
  • PDF — .pdf (требуется наличие текстового слоя)
  • Word — .docx
⚠️ Внимание для PDF: Файлы, созданные из изображений (скан-копии), не содержат текстового слоя и не могут быть обработаны. Используйте PDF, экспортированные из Excel или Word.

Выбор столбцов (ColumnSelector)

После загрузки файла откроется окно выбора столбцов:

  1. Нажмите на заголовок столбца, содержащего названия радиаторов — столбец станет «Наименование»
  2. Нажмите на заголовок столбца, содержащего количество — столбец станет «Количество»
  3. Цвет фона таблицы подсказывает состояние: 🔴 красный — ничего не выбрано, 🟡 жёлтый — выбран только Наименование, 🟢 зелёный — выбрана полная пара
  4. Можно выбрать несколько пар столбцов (если в файле несколько таблиц)
  5. Нажмите «Продолжить»

Выбор страниц PDF

Если PDF содержит более 5 страниц, откроется диалог выбора страниц:

  • Клик по миниатюре — выбор/отмена выбора страницы
  • Можно ввести диапазон вручную (например: 1-5, 10, 15-20)
  • Кнопки «Выбрать все» и «Очистить все»
  • Выбирайте только страницы с таблицами (чертежи и приложения пропускайте)

Мастер подбора аналогов

После обработки файла откроется окно «Мастер подбора аналогов». Здесь отображаются все распознанные строки спецификации.

🎨 Цветовая индикация: Строки сгруппированы по типу радиатора. Одинаковый цвет фона — одинаковые модели конкурента.

По образцу (шаблон)Применён сохранённый ранее шаблон
Ручной вводАналог выбран пользователем вручную

Ручной подбор аналога

  1. Выделите строку с статусом «Не подобрано» (или любую другую для замены)
  2. Нажмите кнопку «Выбрать аналог LaggarTT»
  3. В открывшемся окне укажите параметры:
    • Вид подключения (VK-правое, VK-левое, K-боковое)
    • Тип радиатора (10, 11, 20, 21, 22, 30, 33)
    • Высоту и длину (в таблице-матрице)
  4. Нажмите «ВЫБРАТЬ»
🤖 Обучение программы: После ручного подбора программа анализирует структуру названия и создаёт шаблон. При следующей загрузке все названия с такой же структурой будут подобраны автоматически.

Работа с матрицей

Матрица — это таблица, где строки соответствуют высоте радиатора (300, 400, 500, 600, 900 мм), а столбцы — длине (от 400 до 3000 мм с шагом 100).

  • В ячейки матрицы вводится количество радиаторов
  • Поддерживается формат 1+2 — означает 3 штуки (суммируется)
  • При наведении на ячейку появляется подсказка с ценой и параметрами
  • Стрелками на клавиатуре можно перемещаться между ячейками

Кронштейны и скидки

  • Тип кронштейнов: Настенные / Напольные / Без
  • Скидка на радиаторы, % — применяется ко всем радиаторам в спецификации
  • Скидка на кронштейны, % — применяется только к кронштейнам

Предпросмотр спецификации

После заполнения матрицы нажмите «Предпросмотр». Откроется окно с итоговой таблицей:

  • Все цены пересчитываются с учётом скидок
  • Можно добавить дополнительные кронштейны (из выпадающего списка)
  • Двойной клик по количеству кронштейнов — редактирование
  • Delete или правый клик → удаление строки с кронштейном
  • Клик по заголовку «Артикул» — копирование всех артикулов в буфер обмена
  • Клик по заголовку «Кол-во» — копирование всех количеств

Экспорт в Excel

Из окна предпросмотра нажмите «Экспорт в Excel». Программа создаст файл с двумя листами:

  • Спецификация — таблица с артикулами, наименованиями, ценами и количествами
  • Таблица соответствия — оригинальные названия и подобранные аналоги (если есть данные)

Файл автоматически откроется в Excel.

Сброс данных

Кнопка «Сброс» выполняет следующие действия:

  • Очищает матрицу (все введённые количества)
  • Сбрасывает скидки на 0%
  • Очищает данные таблицы соответствия
  • Закрывает все вспомогательные окна
💡 Рекомендация: Используйте «Сброс» перед загрузкой новой спецификации, чтобы избежать смешивания данных.

Решение проблем

❌ Нераспознанные названия
Откройте «Аналоги», найдите строку, нажмите «Выбрать аналог LaggarTT» и подберите вручную. Программа запомнит формат.
❌ PDF не читается
Убедитесь, что PDF содержит текстовый слой (не является сканом). Попробуйте конвертировать PDF в Excel или скопировать данные через буфер обмена.
❌ В Excel появился лишний лист «Таблица соответствия» со старыми данными
Нажмите «Сброс» перед новой загрузкой. Это очистит сохранённые данные таблицы соответствия.
✅ Программа не запускается или вылетает
Убедитесь, что в папке с программой есть файл Мономатрица.xlsx. При необходимости скачайте актуальную версию.
