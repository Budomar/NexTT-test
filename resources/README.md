# NexTT 2.0 — Подбор радиаторов LaggarTT

Программа для автоматического подбора радиаторов LaggarTT,
формирования спецификаций и расчёта стоимости.

## Возможности

- Подбор радиаторов по типу, размерам и подключению (VK-правое, VK-левое, K-боковое)
- Автоматический расчёт кронштейнов (настенных и напольных)
- Формирование спецификаций с учётом скидок
- Экспорт в Excel с листом спецификации и таблицей соответствия
- Импорт данных из Excel, CSV, PDF
- Автоматический подбор аналогов LaggarTT для радиаторов конкурентов
- Обучение паттернов распознавания названий
- Просмотр параметров радиатора при наведении (мощность, вес, объём, цена)
- Адаптивный интерфейс (поддерживает любые DPI и масштабирование)

## Установка

### Для пользователей

Скачайте `NexTT-2.0.exe` из папки `dist/` и запустите.
Никаких дополнительных действий не требуется — все библиотеки уже внутри.

### Для разработчиков

```bash
git clone <репозиторий>
cd NextT-2.0
pip install -r requirements.txt
python nextt/main.py
Системные требования
Windows 10/11 (64-bit)

macOS 12+ (экспериментально)

Linux (экспериментально)

Использование
Основной экран
Выберите вид подключения (VK-правое, VK-левое, K-боковое)

Выберите тип радиатора (10, 11, 20, 21, 22, 30, 33)

Заполните матрицу — укажите количество радиаторов для нужных размеров

Выберите тип кронштейнов и скидки

Нажмите «Предпросмотр» для проверки или «Создать спецификацию» для экспорта

Загрузка спецификаций
Excel/CSV с артикулами LaggarTT — автоматически заполняет матрицу

Чужие спецификации — открывается мастер подбора аналогов:

Выберите столбцы с названиями и количеством
Проверьте автоматически подобранные аналоги
Для ненайденных — выберите вручную через матрицу
Нажмите «Перенести в матрицу»
Горячие клавиши

Delete — удалить выбранные строки
